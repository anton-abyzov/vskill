Use only these in replies and posts. Re-check pricing and Founders numbers before quoting them.

## Safe to say

- **S01.** SpecWithCode is one interface over the coding agents' own native harnesses; it does not replace their agent loop, tools or sign-in. Wording: "One interface for Claude Code, Codex, GitHub Copilot and more, each in its own native harness on your computers." Source: https://spec-weave.com/code. Evidence: Live /code hero, WebFetch 2026-11-03; also docs-site/docs/studio/harnesses.md: 'SpecWithCode is an interface. It runs no agent loop of its own.'
- **S02.** Supported harnesses are Claude Code, Codex, GitHub Copilot, Gemini CLI, Grok Build, Cursor, OpenCode, Pi, Antigravity, Muse Code and other ACP agents. Wording: "Claude Code (Agent SDK), Codex (Codex app-server), GitHub Copilot and Gemini CLI (ACP Registry), Grok Build (ACP), Cursor (Cursor SDK), OpenCode (HTTP API)" Source: https://spec-weave.com/docs/studio/harnesses. Evidence: Supported harnesses table in docs-site/docs/studio/harnesses.md; /code harness diagram (src/components/code/Harness.tsx) lists the first 7 plus Other ACP agents. Safe list for replies: the 7 in the brief. Caveat from the doc: an ACP Registry entry is 'a candidate, not proof'; Copilot ACP currently lists no models on the owner's Copilot Free account (memory index), so don't claim Copilot model choice.

Wording: "Early access for macOS 13 or later on Apple silicon, Windows 10 and 11 (x64 and arm64), and Linux (x64 and arm64)." Source: https://spec-weave.com/code. Evidence: Live /code requirements line. Same source: 'Mac releases are signed and notarized; Windows and Linux installers are unsigned.' Do not say Intel Mac support.

Wording: "A Mac, a Linux machine on x64 or arm64, or a Windows 10 or 11 PC on x64 can join as a worker over Connect." Source: https://spec-weave.com/code#machines.
